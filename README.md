# Cristalix Support

Приложение для Windows 10/11 с общей базой ответов технической поддержки. C# / WPF / .NET 10. Серверная API работает с PostgreSQL; поиск по смыслу использует локальную ONNX-модель.

## Запуск

Распакуйте архив в постоянную папку и откройте `CristalixSupport.exe`. .NET включен в сборку. Для доступа к ответам нужен общий пароль администратора базы. В исходниках и архиве нет ответов, паролей, токенов или учетных данных PostgreSQL.

`connection.json` содержит публичный адрес API и отпечаток сертификата. При своем HTTPS-домене укажите его адрес и оставьте отпечаток пустым. Сессия и кеш шифруются для текущего пользователя Windows. Выйти из базы можно в настройках; выход очищает локальный доступ. Локального пароля и автоблокировки нет. Сохраненная база доступна без сети до 24 часов после успешной проверки сервера.

## Интерфейс

- Стандартная рамка Windows с системным меню, сворачиванием и разворачиванием. Окно есть на панели задач; его можно переносить за рамку и менять размер за края. Размер, положение и состояние запоминаются. Двойной щелчок по заголовку разворачивает окно.
- Кнопка закрепления включает или отключает отображение поверх других окон. Состояние сохраняется.
- Слева список проблем, справа выбранный ответ. Границу между ними можно двигать. Закройте карточку крестиком, чтобы расширить список; выберите другую проблему, чтобы вернуть карточку.
- Категория поддерживает ввод и фильтрацию. Дополнительные параметры поиска раскрываются отдельно. Есть фильтры по системе, избранному и недавним ответам, темы и масштаб.
- Если у ответа назначена команда, она видна в списке и в карточке. `..интернет` и `/интернет` обозначают одну команду: введите ее в другом приложении и нажмите пробел. Текст заменяется без отправки сообщения. При нескольких вариантах открывается выбор. Уведомление показывает вставленный ответ.
- Поиск включает команды вставки: можно вводить слово с префиксом или без него. В параметрах выберите «Только команды вставки» для отдельного поиска. Буквы е и ее вариант с двумя точками, а также ь/ъ считаются одинаковыми; текст ответов сохраняется дословно.
- Вопрос может содержать несколько вариантов и шагов. Выберите вариант над ответом; условия и номера шагов не копируются. В редакторе можно добавлять, удалять и менять порядок вариантов.
- Закрытие окна по умолчанию оставляет приложение в трее и сохраняет работу команд. В настройках это можно отключить. «Выход» в меню трея полностью завершает приложение. Автозапуск включается отдельно.

Команды вставки работают в обычных текстовых полях приложений с таким же уровнем прав. Они не сохраняют и не передают набираемый текст. Перемещение курсора или смена окна отменяет незавершенную замену.

### Сочетания клавиш

| Сочетание | Действие |
|---|---|
| Ctrl+Alt+Space | Открыть или скрыть окно |
| Ctrl+Alt+B / Ctrl+L | Список команд вставки |
| Ctrl+F | Поиск |
| Ctrl+Enter | Скопировать выбранный вариант |
| Ctrl+Shift+Enter | Поиск по смыслу |
| Ctrl+N | Новый ответ |

Глобальные сочетания настраиваются. Команды и избранное сохраняются локально; изменение ответа синхронизируется со всеми подключенными пользователями.

## Разработка

Откройте `CristalixSupport.slnx` в актуальной Visual Studio с компонентами «Разработка классических приложений .NET», .NET 10 SDK и «ASP.NET и веб-разработка» для API. Для скриптов проверок нужен Python 3.12+.

```powershell
./build.ps1
./build.ps1 -Publish
```

Архив появляется в `artifacts/`, серверная сборка — в `artifacts/api/`. Версия берется из `src/SupportDesk.Desktop/SupportDesk.Desktop.csproj`. Проверки используют искусственные ответы и временные базы. Дополнительная проверка интерфейса:

```powershell
dotnet tests/SupportDesk.Tests/bin/Release/net10.0-windows/SupportDesk.Tests.dll --ui
```

`src/SupportDesk.Core` содержит модели и поиск, `src/SupportDesk.Desktop` — интерфейс и команды, `src/SupportDesk.Api` — авторизацию, общую базу и поиск по смыслу. Настройка собственного сервера описана в [server/README.md](server/README.md).

## Публикация и обновления

Рекомендуемое имя публичного репозитория: `support-desk`.

1. Создайте пустой публичный репозиторий `support-desk` в своем GitHub-аккаунте.
2. Загрузите **содержимое** этой папки в корень репозитория: `src`, `tests`, `server`, `.github` и остальные файлы. Не загружайте ZIP одним файлом и не создавайте лишнюю внешнюю папку. Важно включить `.github/workflows/build.yml`.
3. Откройте GitHub → Actions → Build and release → Run workflow. Включите **Create a release from the project version** и запустите. После успешных проверок в Releases появятся `support-desk-windows-v8.5.0.zip` и `SHA256SUMS.txt`.
4. Раздавайте пользователям Windows-архив из Releases. В сборке GitHub Actions адрес репозитория уже настроен. Для локально собранной версии укажите адрес в «Обновления → Публичный репозиторий GitHub», например `ваш-логин/support-desk`, и нажмите «Проверить обновления».

Приложение проверяет версии при запуске и раз в сутки. Проверку можно отключить. Новая версия отмечается на кнопке «Обновления». Нажмите «Скачать и установить»: скачивание можно отменить, архив проверяется по SHA-256, затем отдельный процесс заменяет EXE и перезапускает приложение. Если новая версия не запустилась, возвращается прежний EXE. Предыдущая копия сохраняется рядом под именем `CristalixSupport.exe.previous`. Вход в базу, команды, избранное и подключение сохраняются. Папка приложения должна быть доступна для записи текущему пользователю Windows.

Для следующего выпуска измените `<Version>` в `src/SupportDesk.Desktop/SupportDesk.Desktop.csproj` (например на `8.5.1`), загрузите изменения и снова запустите workflow с публикацией. Можно также создать и отправить тег `v8.5.1`: он должен совпадать с версией проекта. Уже опубликованную версию следует сохранять неизменной; каждый выпуск получает новый номер.

GitHub Actions выполняет сборку и проверки также при push и pull request. Архив содержит только EXE, публичное подключение, настройки обновлений и README. `.gitignore` исключает приватные файлы, модели и результаты сборки. В публичный репозиторий нельзя добавлять пароли, базы и выгрузки чатов.

Версии до 8.5 нужно один раз обновить вручную: полностью выйдите через трей и замените файлы в прежней папке. Дальше установка доступна из приложения. Для проверки настоящего скачивания из GitHub нужен опубликованный релиз; локальные автоматические тесты проверяют замену файлов, запуск и откат на временных EXE.
