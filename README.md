# Cristalix Support

Приложение для Windows 10/11 для поиска и вставки готовых ответов технической поддержки. Для доступа к общей базе нужен пароль от ее администратора.

## Установка

Скачайте Windows-архив из [Releases](https://github.com/JHayz01/support-desk/releases), распакуйте в постоянную папку и запустите `CristalixSupport.exe`. Устанавливать .NET отдельно не нужно.

Обновления доступны через кнопку «Обновления» в приложении.

## Возможности

- Поиск по тексту, категориям и смыслу.
- Несколько вариантов ответа и последовательные шаги.
- Вставка ответов по командам: введите назначенную команду, например `..интернет`, и нажмите пробел.
- Синхронизация общей базы, избранное, темы и масштаб.
- Закрепление поверх окон, работа в трее и настраиваемые сочетания клавиш.

По умолчанию `Ctrl+Alt+Space` открывает окно, `Ctrl+F` включает поиск, `Ctrl+Enter` копирует выбранный ответ. Для полного выхода используйте меню трея.

## Сборка

Нужны Windows, .NET 10 SDK и Python 3.12+.

```powershell
./build.ps1 -Publish
```

Готовые файлы появятся в `artifacts/`. Решение для Visual Studio: `CristalixSupport.slnx`. Настройка собственного сервера описана в [server/README.md](server/README.md).
